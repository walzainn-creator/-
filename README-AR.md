# توقعات وائل الزين — LIVE v4 Server

هذا المشروع يجمع الواجهة والخادم في حزمة واحدة. عند نشره على استضافة Node.js، يفتح المستخدم نفس الرابط ويعمل التطبيق مباشرة دون إدخال رابط خادم يدويًا.

## التشغيل السريع

1. ثبّت Node.js 20 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع مفتاح API-Football في `API_FOOTBALL_KEY` للحصول على بيانات أعمق. يمكن تركه فارغًا وسيعمل المصدر العام الاحتياطي ببيانات محدودة.
4. نفّذ:

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## النشر الدائم

الحزمة تحتوي `render.yaml` و`Dockerfile`. يمكن نشرها كـ Web Service على Render أو أي خادم يدعم Docker/Node. الخطة `starter` في ملف Render مقصودة لخدمة لا تدخل في وضع النوم مثل الخطط المجانية.

بعد النشر، أضف المتغير السري `API_FOOTBALL_KEY` في إعدادات الاستضافة. لا تضع المفتاح داخل HTML.

## نقاط النهاية

- `GET /api/health` حالة الخادم.
- `GET /api/fixtures?days=7` المواجهات القادمة.
- `GET /api/analyze/:fixtureId` تحليل مواجهة واحدة.

## ملاحظة مهمة

الرمز الذي يولده التطبيق هو رمز داخلي لتتبع التوقع وليس كود قسيمة 1xBet. لا يتم ادعاء وجود تكامل رسمي مع 1xBet ما لم توفر المنصة API موثقًا وصلاحيات مناسبة.
